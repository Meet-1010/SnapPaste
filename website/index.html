Three keys from screen to chat

  1. 1

    Capture

    Press ⌃⇧4 and drag over anything. You can also grab a whole window or the entire screen.

  2. 2

    Mark it up optional

    Arrows, boxes, highlights, text, crop and resize, with full undo. Or skip it: Quick Copy puts the image on the clipboard instantly.

  3. 3

    Paste

    Switch to your AI chat, email or doc and press ⌘V. That's it.

Small app, the right features

Region, window or screen

Pixel-exact selection with live dimensions, window picking with highlight, and multi-display support.

Clipboard-first

Every capture lands on the clipboard as a lossless PNG, ready to paste into any app.

Quick annotations

Pen, highlighter, rectangles, ellipses, lines, arrows and text. Erase or move any mark at any time.

Extract text (OCR)

Copy the text out of any screenshot. Recognition runs on your device and never touches the network.

Keyboard-first

Global shortcuts for every action. Change or turn off any of them.

Featherweight

Lives in the menu bar or system tray, about 0% CPU and roughly 13 MB of memory when idle. No background work.

Your screenshots stay yours

SnapPaste was built around one rule: capture, copy, forget. There's nothing to sign up for and nothing to sync.

  • No files. Captures live in memory only. No history, no gallery, no temp files.
  • No network. The macOS app is sandboxed without network access. There are no uploads or analytics anywhere.
  • No account. Download it and use it, free.
  • Forgets on its own. The last capture is cleared from memory after 15 minutes (adjustable), or when you quit.
  • Open source. Every line is on GitHub, MIT licensed.

macOS

macOS 14 Sonoma or later · Apple silicon & Intel

Download for macOS .dmg · 2 MB
First launch
  1. Open the DMG and drag SnapPaste into Applications.
  2. Open it. If macOS says it can't verify the developer, go to System Settings › Privacy & Security and click Open Anyway. The app is open source but not notarized by Apple.
  3. Press ⌃⇧4 and allow Screen Recording when asked, then reopen SnapPaste.

Windows Beta

Windows 10 or 11 · 64-bit

Download for Windows .exe · portable
First launch
  1. Run SnapPaste-Windows-x64.exe. No installer needed.
  2. If SmartScreen says "Windows protected your PC", click More info › Run anyway. The app isn't code-signed yet.
  3. Find the icon in the system tray, then press Ctrl+Shift+4 to capture.

Questions

Does SnapPaste save my screenshots anywhere?

No. A capture exists only in memory and on your clipboard. SnapPaste keeps the most recent one so you can edit it or copy it again, and clears it after 15 minutes (you can change that) or when you quit.

Which apps can I paste into?

Anything that accepts pasted images: ChatGPT, Claude, Gemini, Slack, Discord, Messages, email, docs and design tools. The image is a standard lossless PNG.

Why does macOS or Windows warn me when I open it?

Removing those warnings takes paid Apple and Microsoft code-signing certificates, which this free project doesn't have yet. The code is open source, so you can check it or build it yourself. Use Open Anyway on macOS or More info › Run anyway on Windows.

Why does it need Screen Recording permission on macOS?

macOS requires it for any app that reads the screen. SnapPaste only takes the single still image you ask for. It never records continuously, and it doesn't need Accessibility permission.

Is text recognition sent to the cloud?

No. On macOS it uses Apple's built-in Vision framework. On Windows and Linux it uses a small model bundled inside the app. Both work offline.

What does "Beta" mean for Windows and Linux?

Those versions are newer. They're built and tested automatically on Windows and Linux, but they've had less real-world use than the macOS app. If something's off, please open an issue.
